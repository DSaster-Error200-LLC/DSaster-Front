## Branch Strategy

### Naming

```text
{type}/#n
```

Where `n` is the issue number.

* Feature: `feat/#n`
* Task: `task/#n`
* Bug: `fix/#n`

Example:

* `feat/#123`

### Completion

When finished, open a pull request to the `main` branch.
